# 💳 Finance Master Pro

Sistema de controle financeiro simples, rápido e sem backend.

## 🚀 Funcionalidades

- Registro de gastos
- Categorias
- Parcelamento
- Controle de cartão de crédito
- Dashboard com totais
- Armazenamento local (LocalStorage)

## 💻 Como usar

1. Abra o arquivo `index.html`
2. Comece a registrar seus gastos

## 📱 Compatível

- Computador
- Celular

## ⚡ Tecnologias

- HTML
- CSS
- JavaScript (Vanilla)
